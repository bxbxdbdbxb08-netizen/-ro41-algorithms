# Трассировка алгоритмов сортировки и поиска

## 1. Сортировка выбором (Selection Sort)
**Входной массив:** `a = {5, 2, 9, 1, 7}`

Алгоритм на каждом проходе $i$ (от 0 до $n-2$) ищет минимальный элемент в неудаленной части массива и меняет его местами с элементом на позиции $i$.

| Проход $i$ | Индекс минимума (minIndex) | Массив после обмена | Число сравнений на проходе |
| :---: | :---: | :---: | :---: |
| 0 | 3 (значение `1`) | `{1, 2, 9, 5, 7}` | 4 |
| 1 | 1 (значение `2`) | `{1, 2, 9, 5, 7}` | 3 |
| 2 | 3 (значение `5`) | `{1, 2, 5, 9, 7}` | 2 |
| 3 | 4 (значение `7`) | `{1, 2, 5, 7, 9}` | 1 |

* **Общее число сравнений:** $4 + 3 + 2 + 1 = 10$.

---

## 2. Сортировка вставками (Insertion Sort)
**Входной массив:** `a = {4, 3, 2, 1}`

Алгоритм берет элемент (`key = a[i]`) и сдвигает элементы влево до тех пор, пока не найдет для него правильную позицию.

| Шаг ($i$) | `key` (`a[i]`) | Число сдвигов | Массив после вставки |
| :---: | :---: | :---: | :---: |
| 1 | 3 | 1 | `{3, 4, 2, 1}` |
| 2 | 2 | 2 | `{2, 3, 4, 1}` |
| 3 | 1 | 3 | `{1, 2, 3, 4}` |

* **Сколько всего сдвигов?** $1 + 2 + 3 = 6$ сдвигов.
* **Сколько сравнений выполнит алгоритм на уже отсортированном массиве из 4 элементов?** На уже отсортированном массиве каждый элемент сравнивается только с предыдущим (1 сравнение за проход внешнего цикла). Для 4 элементов алгоритм выполнит **3 сравнения**.

## 3. Бинарный поиск (Binary Search)

### Часть А: Поиск $x = 7$ в массиве `{1, 3, 5, 7, 9, 11, 13}`
Индексы элементов: от 0 до 6.

| Шаг | `lo` | `hi` | `mid` | `a[mid]` | Решение / Действие |
| :---: | :---: | :---: | :---: | :---: | :--- |
| 1 | 0 | 6 | 3 | 7 | `a[mid] == 7` — элемент найден на индексе 3. Поиск завершен. |

---

### Часть Б: Поиск $x = 6$ в том же массиве
Трассировка для поиска отсутствующего элемента $x = 6$:

| Шаг | `lo` | `hi` | `mid` | `a[mid]` | Решение / Действие |
| :---: | :---: | :---: | :---: | :---: | :--- |
| 1 | 0 | 6 | 3 | 7 | `6 < 7`, смещаем `hi = mid - 1 = 2` |
| 2 | 0 | 2 | 1 | 3 | `6 > 3`, смещаем `lo = mid + 1 = 2` |
| 3 | 2 | 2 | 2 | 5 | `6 > 5`, смещаем `lo = mid + 1 = 3` |

* **Чем закончится поиск?** Поиск завершится остановкой цикла, так как условие `lo <= hi` (`3 <= 3` на шаге станет неверным или выйдет за границы интервала поиска). Элемент не найден.
* **Какое значение вернёт `LowerBound(6)`?** Функция `LowerBound` возвращает первый индекс элемента, который больше либо равен $x$. В данном массиве первый элемент $\ge 6$ — это число `7` под индексом **3**. Метод вернёт **3**.
